security: add server-side PDF validation using magic bytes

Add server-side content validation to verify uploaded files are actually
PDFs by checking for PDF magic bytes. This prevents malicious files with
spoofed MIME types from being uploaded.

Changes:
- Add PDF magic bytes validation ("%PDF") in upload route
- Read first 8 bytes of file to check for PDF signature
- Handle potential BOM or whitespace before PDF header
- Add comment noting that client-provided MIME types can be spoofed
- Update CVDetailView loading message text (British English spelling)

The client-side MIME type check is kept as a first line of defense for
user experience, but server-side validation ensures only actual PDF files
are processed, preventing potential security issues from malicious file
uploads.
