perf: optimize CSS transitions for better performance

Replace universal selector (*) with targeted selectors to improve rendering
performance. The universal selector was causing performance issues by applying
transitions to all elements, including those that don't need theme transitions.

Changes:
- Remove universal selector (*) transition rule
- Add .with-transition utility class for explicit transition control
- Apply transitions only to interactive elements (buttons, links, cards, ARIA roles)
- Include transform and opacity in transition properties for interactive elements
- Maintain 0.3s ease timing for smooth theme switching

This optimization reduces unnecessary style recalculations and improves
page rendering performance, especially during theme transitions.
